Hubungkan ke Google Sheets

Dompetku menyimpan data kamu di Google Sheets milikmu sendiri — gratis, aman, dan kamu yang kontrol.

1

Buat Google Spreadsheet baru

Buka sheets.new di browser dan buat spreadsheet kosong.

2

Buka Apps Script

Klik menu Extensions → Apps Script, lalu hapus kode default dan tempel kode dari file Code.gs.

3

Deploy sebagai Web App

Klik Deploy → New deployment. Pilih type Web App. Set "Execute as" → Me, "Who has access" → Anyone. Copy URL-nya.

Halo, Dompetku 👋
